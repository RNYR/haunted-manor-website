# Haunted Manor Bot

*A private 1920s haunted-house murder mystery for friends.*

Haunted Manor Bot is a free, non-commercial Discord bot used **only in our private server for a game involving approximately 20 friends**. Each player can roll three secret character traits once and retrieve them later. Trait results are sent as private (ephemeral) Discord responses.

This site publishes information about the bot. **It does not contain player assignments, Discord IDs, or credentials.** The bot is not open for public invitations.
